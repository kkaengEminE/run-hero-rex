# 🏃 Run Hero Rex

픽셀아트 횡스크롤 러닝 + 포켓몬식 배틀 RPG

## 🎮 게임 방법

### 달리기
- **SPACE / ↑ 방향키**: 점프 (공중에서 한 번 더 눌러 2단 점프)
- **클릭 / 탭**: 모바일에서 점프

### 충돌 결과
| 충돌 대상 | 결과 |
|---------|------|
| 🌵 선인장 / 🪨 바위 / 🌳 나무 | **즉시 게임 오버** |
| 🦖 공룡 (6종) | **턴제 배틀 돌입** |
| 🏪 상점 | **아이템/장비 구매 화면** |

### 배틀 시스템 (포켓몬 스타일)
- **⚔️ 공격**: 일반공격 / 마법(MP 소모) / 🔥필살기(게이지 소모)
- **🛡️ 방어**: 적 공격의 70% 감소
- **🎒 아이템**: HP포션, MP포션, 투척 무기, 독 약병 등
- **📊 상태**: 내 장비·스탯 확인
- 이기면 3-2-1 카운트 후 달리기 재개, HP/MP 유지
- 지면 게임 오버

### 🔥 필살기 게이지
- 달린 거리 200m마다 게이지 1칸 충전 (최대 5칸)
- KOF 스타일 — 칸이 채워질수록 강력

### ⚖️ 무게 시스템
- 장비마다 무게가 있음
- 레벨별 무게 한도 초과 시 이동속도·점프력 감소

### 🛍️ 상점
- 달리다 상점 건물과 충돌하면 입장
- **아이템 탭**: 소모품 구매
- **투구/갑옷/무기 탭**: 장비 구매 및 즉시 장착

## 🚀 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 접속

## 📦 배포 (Netlify Drop)

```bash
npm run build
# dist/ 폴더를 https://app.netlify.com/drop 에 드래그
```

| 공룡 | 특징 |
|------|------|
| 티라노사우르스 | 강한 공격력, 빠른 속도 |
